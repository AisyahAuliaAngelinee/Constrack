# Constrack

AI Kanban workspace untuk merancang pekerjaan, berkolaborasi, dan melacak progres.

## Status

Repository disusun ulang berdasarkan rancangan produk baru pada 17 Oktober 2026. Tahap saat ini adalah spesifikasi; aplikasi belum diimplementasikan.

## Dokumentasi

1. [Product & Frontend Blueprint](Constrack-01-Blueprint.md) — visi, stack, fitur, desain visual, arsitektur, dan roadmap.
2. [Spesifikasi Aplikasi & UI Awal](Constrack-02-Spesifikasi-Aplikasi.md) — use case, activity diagrams, sequence diagram, ERD, permissions, API, acceptance criteria, dan wireframe desktop/mobile.

Diagram memakai Mermaid dan dapat dibaca langsung di GitHub. Gambaran UI berupa wireframe struktural, bukan screenshot aplikasi jadi.

## Stack yang direncanakan

Next.js App Router · TypeScript · shadcn/ui · Tailwind CSS · Animate UI · Framer Motion · Lucide/Hugeicons · Redux Toolkit/RTK Query · Supabase · Gemini API.

## Langkah implementasi pertama

Login → create board → create task → move task → refresh untuk memverifikasi data tersimpan. Ikuti milestone dan acceptance criteria pada spesifikasi.

## Branch

`main` merupakan branch utama untuk rancangan dan implementasi baru.
